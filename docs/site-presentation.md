# Site Presentation

## Site Header

```yaml rhidoc-feature
prefix: SH
name: Site Header
description: >-
  Users navigate between Pythoning, Problems, and Microgames and switch themes from a shared site header.
```

- **SH1.** [p] The Site Header appears on every page, replacing the homepage header and the back-link and theme-button row on other pages.
- **SH2.** [p] The Site Header is an island component.
- **SH3.** [p] The Site Header displays “Pythoning”, followed by navigation options “Problems” and “Microgames”, with a right-justified theme button.
- **SH4.** [p] The selected navigation option has an underline highlight.
- **SH5.** [p] “Pythoning” navigates to the homepage and has no selected-page highlight.

## Style

```yaml rhidoc-feature
prefix: STY
name: Style
description: >-
  Users see consistent presentation across the site.
```

- **STY1.** [p] Interface headings and button labels use Title Case, preserving explicitly specified literal labels and filenames.
- **STY2.** [p] Shared styling uses base tokens and themes, with component styles owned by their components.

## Page Footer

```yaml rhidoc-feature
prefix: PF
name: Page Footer
description: >-
  Users can visit saxon.zone and the project’s Github repository from a quiet page footer.
```

- **PF1.** [p] The shared page-level footer replaces the homepage’s previous footer style with a smaller, less prominent presentation.
- **PF2.** [p] The footer centers “saxon.zone | Github”, with a Github icon next to Github and links to saxon.zone and the project repository.
